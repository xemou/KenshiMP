v18 - first public beta (protocol 18)

- Co-op & PvP multiplayer for Kenshi, up to 8 players, host's world shared (NPCs, time, weather, towns)
- Join a game already running: GO TO in the Multiplayer window (or /goto) brings your squad next to a friend
- Town chests hold the same things for everybody; looting is validated by the host
- Other players' names always shown above their characters, in their chat colour
- Player numbers kept between host restarts (same name = same number)
- Version shown in the Multiplayer window title: everybody must have the same one

- The host's save is backed up automatically each time a hosted game starts (KenshiMP\backups, last 5 kept)
- /report (or BUG REPORT in the Multiplayer window): logs, settings and session summary in one folder on the desktop

Back up your saves. Bug reports: github.com/xemou/KenshiMP (attach the /report folder, zipped).
